# 热点监控看板

一个纯 Node.js 的网页版热点监控工具，聚合以下榜单：

- 抖音：热点总榜、同城榜、娱乐榜、种草榜、上升热点
- 微博：热搜榜
- 小红书：热榜

同时会在本地持续保留近 15 日的上榜记录，支持关键词搜索。

## 启动方式

```bash
npm start
```

默认访问地址：

```bash
http://localhost:3000
```

## 说明

- 前端每分钟轮询一次最新数据。
- 后端每 5 分钟自动刷新一次，并把历史记录写入 `data/hot-monitor-store.json`。
- 抖音同城榜支持页面内切换预设城市；如需更多城市，可在 `server.mjs` 的 `CITY_PRESETS` 中追加城市代码。
